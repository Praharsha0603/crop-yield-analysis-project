# 🌾 Crop Yield Analysis Project

## 📌 Project Overview
This project analyzes global crop yield data using Python, SQL, and Power BI.

The objective is to identify how environmental factors such as rainfall, temperature, and pesticide usage influence crop productivity across different regions and crop types.

---

## 🛠 Tools Used

- Python
  - Pandas
  - NumPy
  - Matplotlib
  - Seaborn

- MySQL

- Power BI

---

## 📊 Project Workflow

### 1. Data Cleaning
- Removed unnecessary columns
- Checked missing values
- Standardized dataset structure

### 2. Exploratory Data Analysis (Python)
- Crop yield distribution
- Yield trends over time
- Temperature vs Yield analysis
- Rainfall vs Yield analysis
- Correlation analysis

### 3. SQL Analysis
Key business questions answered:

- Which crops have the highest average yield?
- Which regions produce the highest yields?
- How does temperature affect yield?
- How does rainfall impact productivity?
- Which crops receive the highest pesticide usage?

### 4. Power BI Dashboard
Created an interactive dashboard with:

- KPI Cards
- Crop Yield Analysis
- Regional Yield Analysis
- Environmental Impact Analysis
- Interactive Filters

## 📈 Key Insights

- Crop yield varies significantly across crop categories.
- Environmental factors such as rainfall and temperature influence productivity.
- Certain regions consistently achieve higher yields.
- Pesticide usage differs substantially among crops.
